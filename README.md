# ULTY.GG for Windows

This repository only hosts the Windows installers of [ULTY.GG](https://ulty.gg).

**Download the latest version:**
[ULTY.GG-Setup.exe](https://github.com/vicxelcode/ulty-releases/releases/latest/download/ULTY.GG-Setup.exe)

The app updates itself after installing it. Every installer is signed, and the app verifies
the signature of each update before running it.
